# Design System

## Grid (Kunci portfolio ini beda)

**Desktop (min-width: 1024px):**
- 12-column grid
- Konten utama: 8 kolom (offset 2 atau 4, tergantung section)
- Margin notes: 3 kolom (di kanan)
- Header: full width

**Mobile:**
- Single column
- Margin notes jadi inline (di bawah paragraf)

## Typography Scale

| Level | Desktop | Mobile | Weight |
|-------|---------|--------|--------|
| H1 | 3rem | 2rem | 500 |
| H2 | 2rem | 1.5rem | 500 |
| H3 | 1.25rem | 1.125rem | 500 |
| Body | 1rem | 0.875rem | 400 |
| Small | 0.875rem | 0.75rem | 400 |

## Yang GAUSAH punya background/border:
- Card (jangan pake card!)
- Button (kecuali tombol yang beneran bisa diklik)
- Section container

## Hover effect (cuma untuk link)
- Muncul underline dari kiri ke kanan
- Warna berubah ke aksen (#E85D04)
- Durasi: 150ms
