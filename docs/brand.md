# Brand Identity

- Metodikal (bukan asal jadi)
- Jujur tentang kegagalan (banyak portfolio pamer sukses doang)
- Rapi tapi gak kaku

| Teks utama | Hitam | #1A1A1A |
| Teks sekunder | Abu tua | #555555 |
